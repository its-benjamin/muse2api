Muse2API Cookie Import

Sync this browser's muse.ai login session to your muse2api service in one click.

Before you start, confirm two things:
1. You are logged in to muse.ai in this browser (chat UI visible).
2. The service URL and API Key above are filled in (copy them from the top of the "Account Pool" page in the muse2api admin panel).
This extension does one thing only: it reads muse.ai cookies via the browser chrome.cookies API (including httpOnly ones) and POSTs them to the service URL you entered. Nothing is collected or uploaded to any third-party server.
